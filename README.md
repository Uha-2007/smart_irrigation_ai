# SMART IRRIGATION PREDICTION USING AI

## About

Smart Irrigation Prediction Using AI is a web-based system
that helps farmers make better irrigation decisions using
Artificial Intelligence, weather data and agricultural information.

## Main Features

- Farmer login
- Multiple language support
- Farm details
- Weather information
- Sensor-based irrigation prediction
- Sensorless irrigation prediction
- AI-based irrigation prediction
- Water requirement estimation
- Pump duration estimation
- Irrigation history
- Voice assistant

## AI Model

The project uses Random Forest for irrigation
classification and water requirement estimation.

## Irrigation Modes

### Sensor Based

Uses actual soil moisture data from a physical sensor
along with weather and crop information.

### Sensorless

Estimates irrigation requirement using weather and
agricultural information without a physical soil-moisture sensor.

## Goal

Right Water • Right Time • Right Decision
